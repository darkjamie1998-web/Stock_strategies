📖 体系概述

在确认大盘处于有利趋势环境后（三维共振系统判断），本策略通过"行业四维打分体系"筛选具备上涨潜力的行业赛道。

该体系从行业景气度、政策面、资金面、技术面四个维度进行独立评估，每项满分为1分。

  • ✅ 总分达到 3分及以上 视为具备配置价值（潜伏信号）
  • ✅ 4分 为强买入信号
  • ❌ ≤2分 观望/淘汰

🎯 四维评分标准

维度一 行业景气度（1分）

行业类型 得分条件
周期性行业 处于底部或底部反转阶段 ✓
非周期性行业 处于成长期或成熟期 ✓

维度二 政策面（1分）

  • ✅ 有国家层面支持性政策
  • ✅ 存在近期催化事件
  • 两者均需满足才得1分

维度三 资金面（1分）

  • ✅ 股票类ETF月度净申购金额 > 0
  • ✅ 公募基金季度仓位未出现下降
  • 两者均需满足才得1分

维度四 技术面（1分）

触发任一技术信号即可得1分：

⚡ 意外大跌抄底 - 行业指数或龙头股出现意外大跌
🚀 1020起爆点 - 站上10日与20日均线
🐉 龙回头 - 回调后再度走强

💡 操作建议

4分

优先配置，可重仓参与，重点关注科技类成长产业

3分

具备配置价值，可适度建仓，等待进一步催化

≤2分
观望/淘汰

不具备配置价值，应回避或减仓

⚠️ 注意事项

  • 🔄 定期复盘：每周复盘一次行业评分
  • 📊 及时调整：淘汰得分降至2分以下的行业
  • 🔄 切换赛道：及时切换至新晋高分赛道
  • 📈 结合大盘：仅在三维共振确立的上升趋势环境中启用
  • ⚠️ 风险控制：严禁机械照搬评分结果，必须坚守离场底线
