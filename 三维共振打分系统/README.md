# 三维共振打分系统

高志强工作室专属 - 大盘趋势判断工具

## 系统概述

本系统基于"大盘三维共振系统判断条件"，通过三个维度对大盘趋势进行量化评分：

1. **政策面**（1分）：通过千问大模型API分析当前政策环境
2. **资金面**（1分）：基于中证全指成交量数据分析
3. **技术面**（1分）：基于中证全指10日/20日均线分析

## 评分标准

| 总分 | 市场状态 | 建议仓位 |
|-----|---------|---------|
| 3分 | 单边上行行情 | 70-100% |
| 2分 | 横盘震荡行情 | 30-70% |
| ≤1分 | 单边下跌行情 | 0-30% |

## 技术说明

### 政策面评分（千问API）
- 使用提示词模板引导大模型分析
- 分析维度：货币政策、财政政策、资本市场改革、产业政策
- 输出JSON格式结果，包含得分和详细分析

### 资金面评分（中证全指）
- 数据来源：akshare获取中证全指历史数据
- 判断依据：成交量变化率和持续性
- 得分标准：成交量放大>20%且持续性好得1分

### 技术面评分（中证全指）
- 数据来源：akshare获取中证全指历史数据
- 判断依据：10日/20日均线突破情况
- 得分标准：站稳双均线且持续2天以上得1分

## 注意事项

1. **政策面分析耗时**：调用千问API需要30-60秒，请耐心等待
2. **网络依赖**：需要网络连接获取实时数据
3. **数据更新**：中证全指数据为日级数据，建议每日分析一次
4. **风险提示**：本系统仅供参考，不构成投资建议
